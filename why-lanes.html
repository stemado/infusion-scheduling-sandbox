Where does a lane’s capacity come from?

From the real resources behind the plan. Here, two lanes work because two chairs and two nurses can cover two patients at once. Lane 1 need not become chair 1.

Drawing another lane would not add another usable place.

Could a chair board do the same thing?

Yes. A chair board that allows future assignments to move can find exactly the same fit. The benefit comes from keeping choices open, not from the drawing.

What counts as a wrong answer?

First define positive = this request can fit under the current agreed rules. “Filled” and “empty” describe occupancy. The labels below compare a yes/no scheduling decision with whether a valid placement exists.

“It cannot fit”False negativeA missed arrangement that the rules allow.True negativeA correct rejection.

With both nurses until 10, rejecting C just because the initial chair choices look full would be a false negative only if rearrangement is allowed. Changing the display alone does not establish or improve error rates.

A reservation can be a valid rule.

If policy reserves a 240-minute block for long visits, hiding a 120-minute request may correctly honor that policy. It is a false negative only when the agreed policy permits the shorter visit and a valid placement exists.

A later surprise changes the problem.

If a nurse becomes unexpectedly unavailable after a valid booking, the schedule needs repair. That change alone does not make the original decision a false positive. The toggle above changes information known before booking.

Three different questions

Forecast: what is likely?

Estimate future demand, such as the mix of visit lengths. A forecast can guide reservations; it does not establish that a particular request can be staffed.

Feasibility: can this fit?

Find an assignment that meets the agreed hours, capacity, room, and timing rules. The nurse toggle checks this question.

Optimization: which fit is best?

Compare feasible plans using a chosen goal, such as shorter waits or better use of time. The fullest grid is not automatically the best plan.

Useful names: operations research studies decisions like these. Constraint-based scheduling finds plans that obey rules. Resource pooling and deferred assignment keep suitable chair and nurse choices open.
